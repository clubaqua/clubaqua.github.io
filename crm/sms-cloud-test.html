이베스트 클라우드 연결 검증

사용자의 브라우저·연결 프로그램을 거치지 않고 실제 클라우드 서버가 이베스트에 접속하는지 확인합니다.

접속 확인 전용입니다. 이베스트 계정정보를 받거나 저장하지 않으며, 로그인·문자 발송·포인트 차감은 실행하지 않습니다.

실제 클라우드 접속 확인

아래 버튼으로 검증을 시작하세요.

로그인 페이지 응답, 암호화 공개키, 서버 세션 발급 여부만 확인합니다. 이베스트 로그인 성공을 뜻하지 않습니다.

검증 범위

  • 실제 서버 → 이베스트 로그인 페이지 접속: 위 버튼으로 확인
  • 동적 RSA 암호화·세션 쿠키 재사용·잘못된 로그인 중단: 가상 응답 테스트 통과
  • 실제 계정 자동 로그인·잔액 조회: 저장 범위 승인과 계정 초기 연결 필요
  • 실제 문자 발송·수신·포인트 차감: 미검증

다음 단계에 필요한 계정 저장 범위

자동 로그인을 구현하려면 현재 CRM의 Supabase 서버 내 암호화 저장소(Vault)에 이베스트 아이디·비밀번호·로그인 세션을 보관하고, 서버가 이를 복호화해 이베스트 로그인과 포인트·발신자 조회에 사용해야 합니다.

이 범위의 승인을 받은 후 초기 연결 입력란을 활성화할 수 있습니다. 지금은 비밀번호 입력란과 계정정보 전송 기능이 없습니다.
