이베스트 클라우드 연결 검증

서버가 이베스트에 로그인하고 잔액·발신자를 조회합니다. 연결 프로그램과 사용자 브라우저의 이베스트 로그인은 필요하지 않습니다.

현재 단계는 로그인·조회 검증입니다. 문자 발송과 포인트 차감은 실행하지 않습니다. 추가 기기 인증을 요구하면 자동 로그인을 중단합니다.

1. CRM 인증

CRM 로그인과 2차 PIN 확인이 필요합니다. 먼저 같은 탭에서 CRM에 로그인한 뒤 이 페이지로 돌아오세요.

2. 이베스트 최초 연결

이베스트 계정은 처음 한 번 입력합니다. 서버에 저장된 세션을 먼저 사용하고, 세션이 만료되면 저장된 계정으로 다시 로그인합니다.

연결 해제로 현재 저장된 계정과 세션을 삭제할 수 있습니다. 비밀번호를 화면이나 로그에 표시하지 않습니다.

현재 검증 범위

  • 실제 클라우드 → 이베스트 로그인 페이지 접속·공개키·세션 발급: 확인 완료
  • 로그인 암호화·세션 재사용·오류 중단: 가상 응답 테스트 통과
  • 실제 계정 자동 로그인·잔액·발신자 조회: 최초 연결 후 결과 표시
  • 실제 문자 발송·수신·포인트 차감: 미검증 · 발송 기능 비활성
