SMS2 · CRM에서 직접 문자 발송

연결 프로그램 2.0 설치·업데이트

  1. 연결 프로그램 2.0 ZIP 다운로드 후 압축을 풉니다.
  2. PC Chrome 주소창에 chrome://extensions 또는 Edge에서 edge://extensions를 입력합니다.
  3. 기존 1.0 연결 프로그램이 있다면 해당 프로그램을 제거합니다. ‘개발자 모드’를 켜고 ‘압축해제된 확장 프로그램을 로드’에서 새 manifest.json이 있는 폴더를 선택합니다. 표시 버전이 2.0.0인지 확인합니다.
  4. 같은 브라우저 프로필의 CRM과 이베스트 탭을 모두 새로고침합니다. 이베스트에는 본인 계정으로 로그인한 뒤 홈 탭을 열어둡니다.

1.0의 기존 SMS 메뉴도 2.0에서 계속 사용할 수 있습니다. 이번 프로그램은 쿠키·비밀번호를 수집하지 않습니다. 로그인 세션은 이베스트 탭 내부에서만 사용합니다.

CRM에서 바로 보내기

  1. CRM의 SMS2 메뉴를 엽니다.
  2. 포인트·발신자 조회를 눌러 계정, 발신번호, 포인트와 단가를 확인합니다.
  3. 받는 고객을 여러 명 체크하고 공통 본문을 작성합니다.
  4. 수신동의·차감포인트 확인란을 체크합니다.
  5. 선택 고객에게 문자 발송을 누르고 확인창의 수신자·본문·비용을 확인하면 실제 발송 요청이 전송됩니다. 이베스트 발송 버튼을 따로 누르지 않습니다.

발송은 기존 이베스트 포인트에서 차감됩니다. 이베스트 화면으로 수신자·본문을 옮기지 않고 로그인된 탭에서 같은 발송 서버를 호출합니다. CRM의 비밀번호 저장이나 별도 문자업체 가입은 필요하지 않습니다. 모바일에서는 이 PC용 연결을 사용할 수 없습니다.

이번 버전 범위와 결과 확인

  • 즉시 SMS/LMS, 한 번에 최대 100명. 사진 MMS와 예약전송은 기존 SMS 메뉴 또는 이베스트 화면에서 이용하세요.
  • 광고·무료수신거부 안내를 자동 포함합니다. 수신거부 고객을 선택할 수 없으며 발송 전 고객 수신동의를 직접 확인해야 합니다.
  • 이베스트 서버시간 기준 20:50 이후~08:00에는 발송하지 않습니다. 발송시간·포인트·제한을 우회하지 않습니다.
  • 포인트 조회는 조회 버튼을 누른 시점의 값이며 발송 직전에 단가·포인트·발신번호·시간을 다시 검사합니다.
  • ‘서버 접수’는 휴대전화 수신 성공이 아닙니다. 발송제한 대상이나 실패 여부는 이베스트 발송결과에서 확인하세요.
  • 통신이 끊기면 이미 발송됐을 수도 있어 자동 재시도하지 않습니다. 이베스트 발송결과를 확인한 뒤 재발송하세요.
  • 실제 발송 시험은 아직 수행하지 않은 테스트 버전입니다. 본인 번호 1건으로 먼저 확인하세요.
