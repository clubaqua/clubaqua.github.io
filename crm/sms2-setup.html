SMS 발송(직접식) · 예약/MMS

연결 프로그램 2.2 설치·업데이트

  1. 연결 프로그램 2.2 ZIP 다운로드 후 압축을 풉니다.
  2. PC Chrome 주소창에 chrome://extensions 또는 Edge에서 edge://extensions를 입력합니다.
  3. 기존 1.0/2.0/2.1 연결 프로그램이 있다면 해당 프로그램을 제거합니다. ‘개발자 모드’를 켜고 ‘압축해제된 확장 프로그램을 로드’에서 새 manifest.json이 있는 폴더를 선택합니다. 표시 버전이 2.2.0인지 확인합니다.
  4. 같은 브라우저 프로필의 CRM과 이베스트 탭을 모두 새로고침합니다. 이베스트에는 본인 계정으로 로그인한 뒤 홈 탭을 열어둡니다.

기존 연결 프로그램을 그대로 두면 예전 시간 차단 코드가 계속 작동합니다. 2.2.0 표시와 두 사이트 새로고침을 반드시 확인하세요.

기존 간접식 메뉴도 2.2에서 계속 사용할 수 있습니다. 이번 프로그램은 쿠키·비밀번호를 수집하지 않습니다. 로그인 세션은 이베스트 탭 내부에서만 사용합니다.

CRM에서 바로 보내기

  1. CRM의 SMS 발송(직접식) 메뉴를 엽니다.
  2. 포인트·발신자 조회를 눌러 계정, 발신번호, 포인트와 단가를 확인합니다.
  3. 받는 고객을 여러 명 체크하고 공통 본문을 작성합니다. 필요한 경우 JPG/JPEG 사진 1장을 첨부합니다.
  4. 즉시 발송은 바로전송, 예약은 예약전송을 선택하고 한국시간 기준 예약일시를 입력합니다. 현재 서버시간 이후부터 31일 이내로 설정합니다.
  5. 수신동의·사진·예약일시·차감포인트 확인란을 체크합니다.
  6. 선택 고객에게 문자 발송을 누르고 확인창의 수신자·본문·비용을 확인하면 실제 발송 요청이 전송됩니다. 이베스트 발송 버튼을 따로 누르지 않습니다.

발송은 기존 이베스트 포인트에서 차감됩니다. 이베스트 화면으로 수신자·본문을 옮기지 않고 로그인된 탭에서 같은 발송 서버를 호출합니다. CRM의 비밀번호 저장이나 별도 문자업체 가입은 필요하지 않습니다. 모바일에서는 이 PC용 연결을 사용할 수 없습니다.

사진 크기 오류 보완

이베스트 발송결과에서 확인된 ‘MMS 첨부파일 이미지 사이즈 초과’ 오류를 줄이기 위해 사진 크기·용량 자동 조정을 추가했습니다. 기존 연결 프로그램 2.2를 계속 사용하며 CRM 새로고침 후 사진을 다시 선택하면 적용됩니다. 실제 사진 수신은 별도 확인이 필요합니다.

이번 버전 범위와 결과 확인

  • SMS/LMS/JPG 사진 MMS의 즉시·예약 발송을 지원하며 한 번에 최대 100명입니다. 원본 JPG/JPEG 사진 1장(최대 5MB)을 선택하면 전송용을 긴 변 480px·60KB 이하로 자동 조정합니다. 원본 파일은 변경하지 않습니다. 이 값은 보수적인 호환 설정이며 모든 통신사 규격을 보장하지 않습니다. 전송 미리보기를 확인하세요. 서버가 사진 규격을 거절하면 발송을 중단합니다.
  • 광고·무료수신거부 안내를 자동 포함합니다. 수신거부 고객을 선택할 수 없으며 발송 전 고객 수신동의를 직접 확인해야 합니다.
  • CRM과 연결 프로그램에는 자체 발송 시간 제한이 없습니다. 이베스트 서버가 제한하는 요청은 서버 거절 사유를 표시합니다. 야간 발송 가능 여부는 아직 검증하지 않았습니다.
  • 포인트 조회는 조회 버튼을 누른 시점의 값이며 발송 직전에 단가·포인트·발신번호를 다시 검사합니다.
  • ‘서버 접수’는 휴대전화 수신 성공이 아닙니다. 발송제한 대상이나 실패 여부는 이베스트 발송결과에서 확인하세요.
  • 통신이 끊기면 이미 발송됐을 수도 있어 자동 재시도하지 않습니다. 이베스트 발송결과를 확인한 뒤 재발송하세요.
  • 실제 야간·예약 발송 및 사진 수신 시험은 수행하지 않았습니다. 본인 번호 1건으로 먼저 확인하세요. 예약 접수는 실제 수신 완료와 다르며 이베스트 예약내역·발송결과에서 확인하세요.
