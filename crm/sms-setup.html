CRM · 이베스트 문자 연결

PC Chrome 또는 Edge에서 사용합니다. CRM에서 준비한 이름·전화번호·본문을 로그인된 이베스트 화면에 입력하고, 실제 발송은 사용자가 이베스트에서 확인합니다. 확장프로그램 설치만으로 자동 발송되지는 않습니다.

처음 한 번 설치

  1. 연결 프로그램 ZIP 다운로드 후 압축을 풉니다.
  2. Chrome에서는 주소창에 chrome://extensions, Edge에서는 edge://extensions를 입력합니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드를 선택합니다.
  4. 압축 푼 폴더 안에서 manifest.json이 들어 있는 폴더를 선택합니다.
  5. CRM과 이베스트 탭을 모두 새로고침합니다. 브라우저 프로필은 같아야 합니다.

접근 권한은 clubaqua.github.io와 ebestm.renaultkoream.com 두 사이트 및 임시 전달자료 저장용 세션 저장소입니다. 로그인 비밀번호·쿠키를 읽거나 CRM 서버에 저장하지 않습니다.

실제 발송 순서

  1. 이베스트에 본인 계정으로 로그인합니다.
  2. CRM의 SMS 발송에서 고객과 공통 문자 내용을 준비합니다.
  3. 수신동의 확인란을 체크하고 이베스트에 입력하기를 누릅니다.
  4. 이름·전화번호·본문을 이베스트에 전달한다는 확인창을 확인합니다.
  5. 열린 이베스트 탭에서 수신자, 발신번호, 본문, 수신거부 안내, 포인트를 확인합니다.
  6. 필요하면 사진첨부·예약전송을 이베스트에서 설정합니다.
  7. 이베스트의 SMS 발송 버튼을 직접 누릅니다. 발송결과 조회에서 성공 여부를 확인합니다.

CRM의 ‘입력 완료’는 발송 성공이 아닙니다. SMS/LMS/MMS 요금은 이베스트가 산정하고 기존 포인트에서 차감합니다. 가상 고객 미리보기에서는 전달할 수 없습니다.

연결이 안 될 때

  • PC Chrome/Edge 같은 프로필에서 CRM과 이베스트를 열었는지 확인하세요.
  • 설치 후 두 사이트를 새로고침하고 CRM의 ‘연결 확인’을 누르세요.
  • 이베스트 세션이 끝났으면 직접 로그인하세요. 전달 대기는 10분 후 만료됩니다.
  • 기존 이베스트 작성 내용·수신자·첨부가 있으면 덮어쓰지 않고 중단합니다. 내용을 보존한 뒤 새 SMS 화면에서 다시 전달하세요.
  • 오류 후에는 ‘연결 대기 취소’를 누르고 이베스트의 일부 입력 상태를 확인한 후 다시 진행하세요.
  • 모바일 브라우저는 이 PC용 확장 연결을 지원하지 않습니다.
  • 이베스트 화면 구조가 바뀌면 입력 연결을 수정해야 할 수 있습니다.
