## 검증

가상 데이터에서 9개 화면 렌더링, 메뉴·활성 상태, 고객 선택/저장/읽기 전용/수정, 수수료 결과, 차계부 저장, 엑셀·백업 다운로드 흐름, CSS 구문/색상 변수/글꼴 굵기를 확인했습니다. 실제 서버 고객을 수정하거나 문자를 발송하지 않았습니다.

## 가이드 적용 시 판단

- 노란색 사용 규칙은 가이드에 명시된 출고 지표 숫자·계약 배지·안내 왼쪽 선도 허용했습니다. 임의의 강조색은 추가하지 않았습니다.
- 첨부 CSS의 500 굵기·변수 외 색상·장식 그림자는 가이드 기준에 맞게 정리했습니다.
- 기존 label이 input을 감싸는 구조는 접근성과 기존 폼 기능을 보존하기 위해 유지하고 field 클래스를 추가했습니다.
- 기존 JS의 id와 class를 보존하고 디자인 클래스를 추가했습니다. 원래 단계 명칭·금액 계산식·발송 조건은 유지했습니다.
- 주소 검색의 격리된 팝업/프레임 문서는 기능과 보안 설정을 보존합니다. SMS 설치 안내 페이지에는 공통 테마를 연결했습니다.
- 모바일 ‘출고’는 출고 건 등록이 있는 차계부에 연결합니다. 출고고객관리는 ‘더보기’에서 별도로 접근합니다.

`index.html?width=375&page=dashboard` 형식의 검토 페이지는 실제 렌더러로 생성한 가상 데이터 스냅샷을 지정한 폭의 iframe으로 표시합니다. 운영 고객 데이터·로그인 세션을 읽지 않으며 기능 조작은 제공하지 않습니다.
